Status interpretation

Stable

Used daily in the default workflow and covered by regular workspace checks.

Evolving

Shipping now, but likely to receive behavior and API refinement in near-term releases.

Scoped

Available behind configuration choices, provider support, or operational guardrails.

Known current limits

  • Provider behavior differs by tool-calling protocol, so integration coverage matters.
  • Some advanced flows depend on local tools and environment setup.
  • Delegated capabilities are constrained by explicit metadata and runtime mode.

Tool execution dispatch

from crates/looprs/src/tools/mod.rs#L470

pub fn execute_tool(name: &str, args: &Value, ctx: &ToolContext) -> Result<String, ToolError> {
    match Tool::from_name(name) {
        Some(tool) => {
            enforce_fs_mode(tool, args, ctx)?;
            tool.execute(args, ctx)
        }
        None => Err(ToolError::UnknownTool(name.to_string())),
    }
}
