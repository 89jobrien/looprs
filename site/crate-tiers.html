Crate Tiers

Role-based classification for the looprs workspace.

Tier definitions

TierMeaningExamples

Promotion criteria

MoveCriteriaEvidence expected

Risk profile by tier

  1. Core: highest regression blast radius, strongest review and verification needed.
  2. Surface: user-visible behavior shifts quickly but should preserve runtime contracts.
  3. Support: internal evolution is faster, but should not leak unstable contracts outward.
Tiers describe architectural responsibility, not team ownership. A single feature often touches multiple tiers and should still preserve dependency direction.
