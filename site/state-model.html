Per-turn metadata lifecycle

Input metadata

User prompt metadata is attached before hook execution so policy and context injectors can branch on user intent.

Enriched metadata

Hook outputs and delegated agent metadata are merged for the active turn, then consumed by inference and tool filtering logic.

Persistence surfaces

Session store

Conversation events can be recorded through configured session store backends for replay and analysis.

Observability

Structured JSONL traces and UI events are emitted to a centralized or project-scoped observability root.

Failure paths

  1. Provider timeout: turn returns an AgentError::Timeout; it does not currently fire OnError or OnWarning.
  2. Tool failure: tool error content is recorded as tool-result text for model follow-up.
  3. Serialization drift: malformed payloads are surfaced through adapter error contexts.
  4. Write failures: session logging is best effort and should not crash the active turn.

State invariants

  • [ok] Messages remain append-only during a turn.
  • [ok] Tool results always reference the originating tool call id.
  • [ok] Usage accounting accumulates per turn and per session.
  • [ok] Compaction only trims old context; it never mutates new user input.
