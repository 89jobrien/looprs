What It Ships

Stable

Runtime Core

Session state, tool loops, provider calls, event firing, and transcript handling in crates/looprs/.

Stable

Extensibility

Repo and user overlays for .looprs/hooks, commands, skills, agents, and rules.

Stable

Tooling Surface

File-aware tools (read, edit, glob, grep) plus nu and bash execution.

Stable

Provider Layer

Anthropic, OpenAI, Gemini, local Ollama, and SDK variants selectable by config and environment.

Stable

CLI + TUI

REPL and runtime facade in looprs-cli, provider menu and chat TUI in looprs-tui.

Evolving

MCP + Delegation

Remote tool composition, delegated tool allowlists, and parallel orchestration are actively expanding.

How Teams Use looprs

Daily coding loop

Keep one long-running session for implementation, testing, and small refactors while preserving context between turns.

Repo automation

Use slash commands and hooks to run project checks, gather diagnostics, and attach outputs to the prompt stream.

Specialized helpers

Load targeted skills and delegated agents for focused tasks without changing runtime core code.

Fast Start

  1. Build once: cargo build --workspace
  2. Set provider env vars or .looprs/provider.json
  3. Launch: looprs
  4. Reference files directly with @path/to/file.rs
  5. Run workspace checks before push with cargo xtask check pre-push
